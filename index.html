Connecting to Firebase…

Connect this app to Firebase

Firebase is configured, but the app couldn't load data — double-check your config values, that Firestore + Authentication are enabled, and that your Security Rules are published.

This app stores its data in Cloud Firestore, private to people you give a login to. Open js/firebase-config.js in a text editor and follow the steps written at the top of that file, then reload this page.

  1. Create a free project at console.firebase.google.com
  2. Register a Web app and copy its config values into js/firebase-config.js
  3. Enable Firestore Database and Authentication → Email/Password
  4. Add each person who should have access under Authentication → Users
  5. Paste the Firestore rules from firestore.rules and publish them

Full walkthrough with step-by-step details is in README.txt inside this download.
